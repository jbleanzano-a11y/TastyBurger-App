# TastyBurger — React + TypeScript

A Tasty Burger restaurant web app built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Menu
Only **Burgers**, **Starters**, and **Drinks** are included.

## Updated UI
- Preserved the original visual style, animations, and typography.
- Changed **Exquisite Burgers** to **Tasty Burgers**.
- Replaced **Book A Table** with **Add to Cart** and a cart icon.
- Added clickable heart/favorite buttons to food cards.
- Removed Latest Blog and Stay Updated/Newsletter sections.
- Cart uses the existing animated sidebar and localStorage.

## Run
```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal (normally `http://localhost:5173`).
